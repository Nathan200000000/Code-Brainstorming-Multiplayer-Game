# Code-Brainstorming-Multiplayer-Game

CodeForge Arena is a polished multiplayer brainstorming game for programmers and CS students. Players pick languages, answer timed challenges, submit ideas, vote, and climb a leaderboard.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy to Vercel
Import this GitHub repository into Vercel and deploy with the default Next.js settings.

The UI works immediately in demo mode. Supabase Realtime can be added later for persistent rooms, presence, ideas, and votes.
